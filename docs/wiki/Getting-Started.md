# Getting started

1. Install Fabric Loader 0.20.1 or newer and Fabric API for Minecraft 26.2 (Java 25).
2. Put `villaging-1.0.0.jar` in your `mods` folder.
3. Join a world. A guide opens the first time; reopen it with `/villaging guide`.
4. A box asks for your AI key. Pick Claude, Gemini or Ollama (free, local). `/villaging key` opens it again.
5. **Sneak + right-click** an ordinary villager and say something. It becomes smart and gets a name. The first player to do this becomes the king.
6. From then on a plain **right-click** opens a full chat. The villager stands still while you talk.

Prefer an item? Craft the **Crown of the King** (gold ingots on top and sides, diamond in the middle of the bottom row), or take it from the creative inventory.

Golems: tell a smart villager "recruit the iron golem" (or copper golem) and approve the pop-up.
