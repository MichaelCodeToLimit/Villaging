# Villaging Discord: ready-made setup

Create a server, then paste these. Turn on Community and a rules screen if you want it.

## Channels
**INFO**
- #welcome (read only)
- #rules (read only)
- #announcements (read only; releases)

**HELP**
- #getting-started
- #bug-reports (ask for log, version, provider)
- #questions

**COMMUNITY**
- #showcase (screenshots and videos)
- #ideas
- #off-topic

## Welcome message
Welcome to the Villaging community! Villaging turns villagers and golems into smart AI helpers you command in plain words. Get the mod at https://modrinth.com/mod/villaging. Need help? Post in #getting-started. Found a bug? #bug-reports with your Minecraft version and `logs/latest.log`.

## Rules
1. Be kind and keep it friendly.
2. Never post your API key. If you do, delete the message and rotate the key right away.
3. Bug reports: include version, provider and log.
4. No piracy, no spam or advertising.
5. English in main channels.

## Roles
Owner, Moderator, Contributor, Member.
